## ✨ Features

- ⚡ **Fully self-contained** — single HTML file with embedded CSS & JS
- 📱 **Responsive design** — works on desktop, tablet, and mobile
- 🎨 **Custom design system** — earthy green palette with Playfair Display & DM Sans fonts
- 🔢 **Animated counters** — live impact numbers (trees planted, funds raised, donors)
- 🖼️ **Interactive gallery** — activity photos with modal/lightbox support
- 💸 **Donation widget** — preset and custom donation amounts with a live fundraising bar
- 🗂️ **Program modals** — clickable cards that expand with detailed program info
- 🔝 **Smooth scrolling** — fixed navbar with scroll-progress indicator
- 📧 **Newsletter sign-up** — email subscription form in the footer
